# Projeto
Um site que serve de repertório para um mestre de RPG. O mestre tera seu cadastro, assim como possiveis pessoas que queiram requisitar seus serviços.

## Foco
O site tem o foco em destacar os serviços do mestre. Informando logo na primeira pagina informações de contato, serviços de mestragem e tutoria. O site contará com a possibilidade de cadastro e agenda para marcar o serviço requisitado. O mestre poderá ver todos os serviços requisitados de maneira organizada, possibilitando maior organização.

## Ferramentas
O site utiliza-se de Vue, TypeScript, MongoDB (Banco de dados não relacional).
